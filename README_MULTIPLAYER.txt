LARO NG BAYAN v5.6 — MULTIPLAYER BETA

IMPORTANT: THIS IS A BETA. It has been tested in two browser instances
using a simulated peer connection. Real two-phone internet/WebRTC joining
must still be confirmed on your devices before it is used at an exhibit.

DEPLOYMENT
1. Extract this ZIP. Upload index.html and palaro-music.mp3 to the root of
   your GitHub Pages repository (or another HTTPS static hosting service).
2. Ensure both phones open exactly the same hosted version and have internet.
3. Phone 1: MULTIPLAYER (P2P) > CREATE ROOM. Share the six-character code.
4. Phone 2: MULTIPLAYER (P2P) > enter code > JOIN ROOM.
5. Host picks one of ten games and selects START MATCH.
6. Both players answer five math questions; both tap READY TO PLAY.
7. The chosen mini-game starts after a short countdown. Scores sync live.
8. Both players finish; the game compares points, then actions, then time.

GAMES
Syato, Kadang sa Bao, Sungka, Agawan Base, Luksong Tinik, Sipa,
Piko, Tumbang Preso, Holen, and Patintero.

MATCH TYPES
- Sungka: direct head-to-head on one shared online board, with real turns.
- Patintero: direct runner-vs-taya online mode is separately available
  from the connected room; standard Patintero also supports score duels.
- Other games: simultaneous score/time challenges, each player using
  the approved original mini-game controls and NPCs where applicable.
  Scores and results appear on both screens, but the players do not
  physically interact on a shared court in these games.

SOLO MODE
The v5.5 solo gameplay code is preserved. No online match awards solo tickets,
gold or achievements. All five existing languages and responsive title remain.
The new multiplayer instructions are currently in English.

NETWORK
Internet, HTTPS hosting, PeerJS Cloud signaling and WebRTC peer connection
are required. Restricted networks, some Android content:// local files,
or offline browsers may fail. Only use room codes with people you know.
No live test on two physical devices has been completed.
